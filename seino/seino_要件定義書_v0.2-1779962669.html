第1章 背景・目的

1.1 背景

発注者(甲)は、既存の人材派遣事業に加え、正社員紹介(エージェント)事業を新規に立ち上げる。当該事業の求職者・企業双方への情報発信および応募受付チャネルとして、専用 Web サイト「SEINO AGENT(セイノーエージェント)」を構築する。

1.2 サイトコンセプト(本体メタディスクリプションより)

SEINO AGENT(セイノーエージェント)は、セイノーホールディングスグループの正社員向け人材紹介サービス。東海エリアを中心に、業種・職種を問わない転職支援と、国家資格キャリアコンサルタントによる伴走をご提供します。

1.3 ブランディング

  • キャッチコピー: 「あなたの経験を、次のキャリアへ。」
  • ブランドカラー(青): #173c88 → #3a6bc8(135度グラデーション)
  • アクセントカラー(赤): #b9292f / 金: #e8c877

1.4 ゴール KPI(参考、合意外)

  1. 公開後 3ヶ月以内に月間 PV 5,000 を達成
  2. 公開後 6ヶ月以内に Web 経由の応募/問い合わせを月 20 件以上獲得
  3. 「東海 転職エージェント」「岐阜 正社員転職」等の SEO 検索流入を確保

5.3 求人データの取扱い

  • 求人情報の登録は甲(セイノー採用担当)が Toroo 管理画面で実施する
  • 求人ごとの画像(サムネイル)は、初期に乙がカテゴリ別(営業/IT/製造/物流 等)の汎用画像 10〜15枚を Toroo に登録、運用フェーズで甲が必要に応じて差し替える
  • 既存 JobGear からの求人データ移行が必要な場合、甲が CSV エクスポートし Toroo にインポートする(キックオフ確認項目 #17)
